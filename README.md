# 🌌 Cosmic Space

**Cosmic Space** is a hackathon project that delivers an interactive space-themed web experience with immersive visuals, modern UI design, and engaging frontend interactions. The project was built to showcase creativity, rapid prototyping, and frontend development skills during a hackathon.

---

## 🚀 Project Overview

The application presents a cosmic-themed interface inspired by outer space, featuring animated visuals and a responsive layout. It focuses on providing an engaging user experience through smooth interactions and aesthetic design.

---

## ✨ Features

- 🌠 Interactive space-themed user interface
- 🪐 Cosmic visual effects and animations
- 📱 Responsive design for desktop and mobile devices
- ⚡ Lightweight and fast-loading frontend
- 🎨 Modern dark-space aesthetic

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ Run Locally

1. Clone the repository:

```bash
git clone https://github.com/su9a-nath/cosmic_space.git
```

2. Open the project folder:

```bash
cd cosmic_space
```

3. Open `index.html` in any web browser.
